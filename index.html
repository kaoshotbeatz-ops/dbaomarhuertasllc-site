Omar Huertas LLC / ServiceNowService areas, 1 to 4

Four disciplines, one platform.

A ServiceNow instance is a long-lived thing. It collects customizations, integrations and half-finished ideas, and the cost shows up years later as upgrades that hurt. The work below is organised to prevent that, from the first scoped application to the last go-live.

Each area stands alone, and they fit together. A clean CMDB makes event management meaningful; a scoped app is only useful if the data under it can be trusted.

Custom applications on the Now Platform, built in their own scope so they upgrade cleanly and stay out of the way. Every one is tested with ATF and prepared to be Store-ready, with the documentation to match.

Feature III / From the labThree projects, none released

One rule for AI that acts: nothing runs until you approve it.

Three projects from our own lab. Real names, real status, nothing released yet. Each one is built around the same rule.

Project file 01In development

Obvera

The IT operations platform where every change is requested, approved, executed and audited. Coming soon.

  • One service for IT.ITSM, MDM, procurement, security and data together, instead of five tools stitched by hand.
  • Nothing changes off the record.Each change is requested, approved, executed and closed, and every write is audited.
  • Built for small teams.Designed for small businesses, non-profits and growing teams. Not yet generally available.

Project file 02Coming soon

Albena

An AI assistant designed to live on your own hardware and ask before anything that matters. In development.

  • Private by design.Built to run on your own Mac or NVIDIA hardware, so your data stays where you put it.
  • Asks before it acts.Low-risk tasks run on their own. Anything that spends, sends or unlocks will wait for your yes.
  • Say it or click it.Talk to it by voice, or use the portal. Same assistant, same rules.
Request access

Project file 03Research preview

AgentGate

Prompt injection makes an agent act on text anyone can write. AgentGate makes being fooled harmless. Coming soon.

  • Tiers come from a manifest.Every tool has a risk tier set in advance, not decided by the model in the moment.
  • Approval bound to the exact action.A signed, single-use token covers one payload for five minutes. Change one character and it fails.
  • An independent check.A separate verifier re-reads every write against the log. Scores come from the log, not the model.

v0 research preview. Defensive only, run in a sandbox with synthetic data. Not yet released.
