Project file 03

AgentGate

Research previewComing soon

Prompt injection makes an agent act on text anyone can write. AgentGate makes being fooled harmless.

  • Tiers come from a manifest. Every tool has a risk tier set in advance, not decided by the model in the moment.
  • Approval bound to the exact action. A signed, single-use token covers one payload for five minutes. Change one character and it fails.
  • An independent check. A separate verifier re-reads every write against the log. Scores come from the log, not the model.

v0 research preview. Defensive only, run in a sandbox with synthetic data. Not yet released.
